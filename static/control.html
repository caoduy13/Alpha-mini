Robot offline / tcp_ok: false — làm gì?
  • Trên app UBTECH hoặc màn hình robot, xem IPv4 Wi‑Fi thật. Mở .env → ROBOT_IP= đúng IP đó, rồi restart server.
  • GET /robot/diagnose (nút bên dưới): timeout thường là sai mạng/IP hoặc robot tắt/ngủ; connection refused thường là tới được máy nhưng cổng 9090 không mở (sai thiết bị, hoặc robot chưa sẵn sàng SDK) — đợi robot online, thử tắt tạm firewall, hoặc ROBOT_TYPE=edu nếu firmware quốc tế.
  • Sau khi sửa IP: Làm mới /status hoặc POST /robot/connect (quét LAN).
  • Ping trên Windows đôi khi báo «General failure» dù mạng ổn (ICMP bị chặn). Đừng chỉ dựa vào ping; ưu tiên IP từ app và kết quả /robot/diagnose.
  • Không cần IP trên mắt robot: trong .env bật ROBOT_AUTO_DISCOVER=true (mặc định trong bản mới) — server dùng SDK quét LAN rồi thử kết nối; có thể bật ROBOT_PERSIST_DISCOVERED_IP=true để ghi IP vào .env. Vẫn dùng POST /robot/connect hoặc nút quét nếu cần.
  • /status: robot_online = SDK đã kết nối (robot_sdk_connected). Xem thêm robot_last_connect_error (lỗi SDK lần cuối). robot_ws_alive chỉ tham khảo — có Wi‑Fi/internet không có nghĩa là đã tới được IP robot.
